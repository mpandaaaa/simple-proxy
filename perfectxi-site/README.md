# perfectxi.app

The website, as served by Netlify (project `projectxi`). It was uploaded by
hand and its source lived nowhere else, so this folder was pulled from the
live site on 14 November 2026 and is now the copy of record.

`netlify.toml` exists on the live site but is not served publicly, so it is
not in this folder. A deploy that sends every file must keep it: use a file
digest deploy that carries its current sha across rather than a folder drop.
